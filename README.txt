BayTag Inventory iPhone PWA v1.4

Publish all files together to an HTTPS static host (e.g. GitHub Pages, Netlify). On iPhone open the HTTPS URL in Safari, tap Share > Add to Home Screen > Add.

Camera photo capture is for reference only; text recognition is not yet implemented. Home Depot search opens their website; automatic SKU data population is not implemented. Data stays in local browser storage, so use Backup JSON regularly. If migrating from another origin, export Backup JSON there and Restore JSON in the new app.

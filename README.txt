BayTag iPhone PWA v2.0

Deploy all files at the repository root on GitHub Pages. Back up JSON before upgrading. This is a static PWA: Home Depot automatic SKU lookup is NOT available. OCR loads Tesseract.js over the network on first use; verify every detected tag. Photos are not saved in inventory. Multi-photo selector allows viewing OCR outlines for each image. Scan results append to unsaved review rows; clear manually if needed. No server sync or cloud backup.
